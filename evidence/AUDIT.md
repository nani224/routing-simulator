## 1. Trace Origin & Provenance Statement (Gate 0 & Gate A)

- **Prior Dataset (Flaw Identified & Corrected):** Traces in the early Phase 4 ablation study were 100% synthetic, generated by a procedural function (`generate_synthetic_site_flow`) with artificial modulo-2 labels. This was disclosed and audited in `/evidence/ml/DATA_AUDIT.md`.
- **Gate A Reworked Dataset (Locally Served Site Profiles):** All 2,400 traces in the current dataset represent real network traffic generated over genuine loopback TCP sockets (`127.0.0.1`) using **60 locally served site profiles** across 5 categories (12 video, 12 tech, 12 news, 12 shopping, 12 collab) with 20 direct flows and 20 tunnel flows per site.
- **Genuine Protocol Stacks:**
  - **Negative Class (Direct Traffic):** Genuine **TLS 1.3 HTTPS (`RFC 8446`)** served via Python's standard `ssl` library using an ephemeral elliptic-curve (SECP256R1) self-signed X.509 certificate. Captured via an intercepting TCP tap.
  - **Positive Class (Tunnel Traffic):** Genuine **Noise XX mutual authentication handshake** (Curve25519, ChaCha20-Poly1305, BLAKE2s) carrying identical site profile payloads over framed wire packets.
- **Storage & Reproducibility:** Dataset cached at `/evidence/ml/captures/flows_dataset.json` with metadata manifest at `/evidence/ml/manifest.json`.
